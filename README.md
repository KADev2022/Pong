# Pong — Python Arcade Game

A modern recreation of the classic Pong arcade game, developed using **Python and Pygame**.

The game combines classic arcade gameplay with animated menus, adjustable AI difficulty, sound effects and visual enhancements.

## Features

- Classic Pong gameplay with player-versus-AI matches
- Three AI difficulty levels: Easy, Medium and Hard
- Dynamic ball speed and bounce angles
- Animated main menu and settings screen
- Particle effects, ball trails and screen shake
- Background music and sound effects
- Adjustable music and sound effects volume
- Fullscreen and windowed display modes
- Persistent settings and high scores
- Standalone Windows executable

## Controls

| Key | Action |
|---|---|
| Up / Down arrows | Navigate menus and move the player paddle |
| Enter | Select a menu option |
| Left / Right arrows | Adjust settings |
| Esc | Pause, resume or return from Settings |
| R | Restart a match from Pause or Game Over |
| Q | Quit from the Pause menu |

## Running from Source

1. Install Python.
2. Clone or download this repository.
3. Install the dependencies:

   `pip install -r requirements.txt`

4. Launch the game:

   `python main.py`

## Windows Release

A standalone Windows version is available from the repository's **Releases** section.

Download `Pong-v1.0.zip`, extract the archive and launch `Pong.exe`.

Python does not need to be installed to run the Windows release.
